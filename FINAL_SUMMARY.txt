  1. Go to "👥 Employees" tab
  2. Add your team members:
     - Name: Ali Khan
     - Phone: +974 3312 2222
     - Branch: Dubai Sales
  3. Repeat for each employee
  4. Done!

STEP 2: CUSTOMIZE (2 minutes)
  1. Go to "⚙️ Settings" tab
  2. Edit WhatsApp message template
  3. Use placeholders: {NAME}, {TASK}, {TIME}, {BRANCH}
  4. Save

STEP 3: CREATE REMINDERS (30 seconds each)
  1. Go to "📝 Tasks" tab
  2. Tap mic button
  3. Speak: "Remind Ali to check inventory tomorrow at 2pm"
  4. Review parsed details
  5. Enable WhatsApp if you want
  6. Click "Create Task & Reminder"
  7. Done!

================================================================================
                        TROUBLESHOOTING
================================================================================

VOICE NOT WORKING?
  ✓ Check Safari Settings → Websites → Microphone → Allow
  ✓ Speak clearly and slowly
  ✓ Try shorter phrases
  ✓ Check internet (HTTPS required)

EMPLOYEE NOT FOUND?
  ✓ Check Employees tab
  ✓ Verify exact spelling
  ✓ Save if not there
  ✓ Use dropdown selector

WHATSAPP NOT OPENING?
  ✓ Is WhatsApp installed? (App Store)
  ✓ Phone number correct? (+974XXXXXXXX)
  ✓ Try manual copy/paste
  ✓ Check app permissions

CALENDAR NOT SYNCING?
  ✓ Check Calendar app installed
  ✓ Verify .ics file opens with Calendar
  ✓ Check notifications enabled
  ✓ Restart Calendar app

For more, see IMPLEMENTATION_GUIDE.md
